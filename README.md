# Géode
Jeu idle satisfaisant (canvas). Le jeu est dans `docs/` (GitHub Pages) ; l'APK Android (`android/`) charge cette page.
- Mise à jour du jeu : modifier `docs/`, pousser sur `main` → l'appli la récupère (bouton « Mettre à jour » dans Missions).
- APK : onglet *Releases* → `Geode.apk` (recompilé quand `android/` change).
